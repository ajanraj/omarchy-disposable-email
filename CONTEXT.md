# Disposable Email

Disposable Email gives Omarchy users two distinct ways to avoid exposing a primary email address.

## Language

**Temporary Address**:
An address intended for one-off use whose messages are read in a provider-hosted public inbox. It is not an inbox owned or managed by the plugin.
_Avoid_: Temporary inbox, temporary alias, disposable alias

**Forwarding Alias**:
An address that forwards messages to the user's existing mailbox. It can be disabled or deleted, but messages are not read inside the plugin.
_Avoid_: Inbox, temporary inbox

**Provider**:
An external service that operates temporary addresses or forwarding aliases.
_Avoid_: Email type, backend

**Known Duck Alias**:
A DuckDuckGo forwarding alias recorded because this plugin created it. Known Duck Aliases are not a complete inventory of the user's DuckDuckGo aliases.
_Avoid_: All Duck aliases, DuckDuckGo alias list
