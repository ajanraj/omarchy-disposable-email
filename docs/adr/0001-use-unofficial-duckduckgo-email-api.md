# Use the unofficial DuckDuckGo Email API

Support DuckDuckGo Email Protection through the bearer-token endpoints used by DuckDuckGo's first-party clients, despite the absence of a supported public API. The plugin will disclose that the integration may break and limit itself to confirmed operations: generate an alias, query a Known Duck Alias's active status, and deactivate or reactivate it. It will not claim to list every account alias or offer deletion, activity, or statistics.
